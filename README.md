# موقع إبداع للتسويق والتطوير التقني

موقع متعدد الصفحات (HTML / CSS / JS) بدون أي مكتبات خارجية، عدا خط Cairo من Google Fonts.

## هيكل الملفات
```
index.html            الصفحة الرئيسية (هيرو، خدمات، أنواع المشاريع، من نحن، عملاء، باقات، أسئلة، مدونة، تواصل)
services.html         صفحة الخدمة (قالب واحد لكل الخدمات)  ← services.html#stores
blog.html             المدونة + صفحة المقال + السايد بار  ← blog.html#post-1
assets/
  css/style.css       الأنماط المشتركة (متغيرات الألوان، الهيدر، الأزرار، الفوتر...)
  css/home.css        أنماط الرئيسية
  css/services.css    أنماط صفحة الخدمات
  css/blog.css        أنماط المدونة
  js/posts.js         بيانات المقالات (مصفوفة P) - مشتركة بين الرئيسية والمدونة
  js/home.js          أنيميشن الهيرو، العدّادات، السلايدر، الأسئلة...
  js/services.js      بيانات الخدمات والباقات (كائن SV) + عرضها
  js/blog.js          القائمة، المقال، البحث، التصنيفات، الأكثر مشاهدة
  img/                الصور والشعار
```

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو شغّل سيرفر محلي: `python3 -m http.server`.

## التعديل من لوحة التحكم
- **المقالات:** `assets/js/posts.js` (id, t, cat, img, d, v, rt, ex, b).
- **الخدمات والباقات والأسعار:** `SV` في أعلى `assets/js/services.js`.
  مفاتيح الخدمات: sites, stores, companies, realestate, law, edu.
- أرقام المشاهدات تُحفظ حالياً في localStorage المتصفح فقط؛ اربطها بقاعدة بيانات.
- نموذج التواصل والنشرة البريدية يعرضان رسالة شكر فقط؛ اربطهما بالإيميل أو API.
- الأسعار والنصوص وبيانات التواصل (hello@example.com) أمثلة، استبدلها ببياناتك.

## ملاحظات
- بعض الصور مقصوصة من تصميم واحد، فاستبدلها بصور أعلى جودة عند توفرها (`assets/img`).
- الشعار: `assets/img/logo.webp`.
